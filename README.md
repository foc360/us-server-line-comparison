## 美国服务器线路类型：163、CN2 GT、CN2 GIA、9929到底差在哪

线路决定速度和稳定性。

**传统163骨干网**是最普通的线路类型，走ChinaNet (AS4134)，全程202.97节点。晚高峰容易卡，丢包率高，但价格便宜。Vultr、RackNerd这些按小时计费的商家基本都是这个线路，月付2.5-3.5美元起。

**CN2 GT**（Global Transit）是CN2线路的中端产品。去程和回程会同时出现202.97和59.43两种节点，只有国际出口才走59.43 CN2节点。比163好一些，但晚高峰还是会受影响。搬瓦工的DC3机房就是CN2 GT，年付49.99美元起。

**CN2 GIA**（Global Internet Access）是CN2线路的高端产品，全程和回程全走59.43高速节点CN2 (AS4809)，稳定、速度快、丢包率低。搬瓦工的CN2 GIA-E方案年付169.99美元起，HostDare的CN2 GIA年付49.99美元起。

**联通AS9929**质量堪比CN2 GIA，部分商家会用联通9929+移动CMIN2的组合做三网优化。ZoroCloud的洛杉矶9929系列就是这个路线，月付39元起。

这些线路的价格从低到高排列：163骨干网 < CN2 GT < 联通9929 ≈ CN2 GIA。如果你的用户主要在国内，163线路晚上八九点基本别想流畅访问；CN2 GIA或9929线路贵一些，但体验差别很明显。
